# NOVESQ Homepage

React + TypeScript + Vite starter homepage based on the NOVESQ brand direction.

## Files

- `App.tsx` — complete homepage
- `index.css` — global reset, fonts and design tokens
- `App.css` — page layout and responsive styles
- `main.tsx` — React entry point
- `index.html` — Vite HTML entry point

## Setup

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. Run `npm run build` to type-check and create a production build, or `npm run preview` to serve that build locally.

The homepage uses no UI framework or icon package.

## Brand

- Deep Navy: `#101C2C`
- Warm Copper: `#C47A5A`
- Warm Off-White: `#F4F1EA`
- Soft White: `#FCFCFA`
- Graphite: `#26313D`
- Muted Sage: `#87998D`

Typography:
- Manrope — brand/headings
- Inter — UI/body

The Google Fonts import can later be replaced by locally hosted fonts for production.
